# 基础

## any、unknow 的区别
**any:** 可以把任何东西分配给any类型，也可以对any类型进行任何操作 <br>
**unknow:** 可以将任何东西赋给 unknown 类型，但在进行类型检查或类型断言之前(unknown 必须先收窄才能访问属性)，不能对 unknown 进行操作
``` typescript
function invokeAnything(callback: unknown) {
  if (typeof callback === 'function') {
    callback();
  }
}
invokeAnything(1);
```

## interface 与 type 区别

1. 相同点：都能描述对象形状、函数签名、联合、交叉。<br>
2. 差异：<br>
– interface 可以同名合并，type 不行。<br>
– type 能表达所有类型（基础类型、联合、元组、映射类型），interface 只能描述对象/函数/类契约。<br>
– 类实现：class C implements I 只能用 interface。<br>
– 性能：interface 在大型项目类型检查更快（可索引合并）。<br>
– 写法风格：interface 偏向面向对象契约，type 偏向类型运算。<br>
